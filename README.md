# Learning & Testing Sandbox

A central sandbox repository dedicated to experimenting with Python concepts, testing libraries, and practicing software engineering patterns.

---

## 🎯 Repository Purpose

This repository organizes hands-on projects, study code, and technical experiments across several core domains:

* **Object-Oriented Programming (`object-oriented-programing/`):** Testing class design, inheritance, loops, and modular architecture 
* **API Integration (`api-requests-lib/`):** Practicing HTTP requests, parsing JSON responses, and consuming REST APIs (e.g., PokéAPI integration).
* **Security & Encryption (`encrypt-and-decrypt/`):** Exploring string manipulation, cipher logic, and custom data obfuscation algorithms.
